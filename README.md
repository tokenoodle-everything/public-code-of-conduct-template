# public-code-of-conduct-template

> Template repository for Tokenoodle Everything custom Code of Conduct

This repository hosts our official reusable Code of Conduct for all `tokenoodle-everything` open-source projects.
It is not the standard Contributor Covenant; this is our tailored, lightweight variant hosted at <https://coc.tokenoodle.com>

## What is included
- `CODE_OF_CONDUCT.md`: Tokenoodle custom Code of Conduct (the text you provided)
- This README
- Template ready for copying into new repos

## Usage
### Copy file manually
Download and place `CODE_OF_CONDUCT.md` at the root of your repository.
```bash
curl -O https://raw.githubusercontent.com/tokenoodle-everything/public-code-of-conduct-template/main/CODE_OF_CONDUCT.md
```
