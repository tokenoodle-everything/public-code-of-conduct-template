# Tokenoodle Everything Code of Conduct Template

A reusable, lightweight Code of Conduct template for Tokenoodle Everything projects.

This repository contains the official Tokenoodle Everything Code of Conduct used for open-source projects. It is intentionally simpler and more tailored than the standard Contributor Covenant, and is designed to be easy to adopt across the ecosystem.

The hosted version is available at https://coc.tokenoodle.com

## Why this repository exists

This template helps maintainers quickly add a clear, consistent community standard to new projects without having to draft a policy from scratch. It is meant to be:
- easy to copy
- lightweight to maintain
- aligned with Tokenoodle Everything values
- suitable for community-driven open-source work

## Included files

- `CODE_OF_CONDUCT.md` — the reusable Tokenoodle Everything Code of Conduct
- `README.md` — usage guidance for maintainers

## How to use this template

### 1. Copy the Code of Conduct into your repository

From the command line:

```bash
curl -O https://raw.githubusercontent.com/tokenoodle-everything/public-code-of-conduct-template/main/CODE_OF_CONDUCT.md
```

Then place the file at the root of your repository as `CODE_OF_CONDUCT.md`.

### 2. Review and customize it

Before publishing, check whether you want to:
- adjust the project-specific language
- add project-specific examples of acceptable behavior
- update contact information for reporting issues
- include links to project communication channels

### 3. Link to it from your project documentation

We recommend linking to the Code of Conduct from:
- your `README.md`
- your `CONTRIBUTING.md`
- your community or project docs
- GitHub repository settings where relevant

## Notes

This repository is a template and should be treated as a starting point for new projects. The official policy for Tokenoodle Everything communities remains the version hosted at https://coc.tokenoodle.com
